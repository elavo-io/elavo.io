Hardware

Elavo is for 64-bit desktop and laptop PCs with Intel or AMD graphics.

Supported

  • 64-bit x86 processors (x86_64), from Intel or AMD
  • Intel or AMD graphics, built in or separate
  • Desktops and laptops

Not yet

  • NVIDIA graphics. NVIDIA's drivers come in a separate image, later. It is not available yet.
  • ARM. There is no ARM build, and none is planned yet.

What we have tested

So far, Elavo has been installed and updated on one laptop. That is not a compatibility list. This section grows as more machines are tested, and it will name the machines.

The test laptop booted the installer with UEFI. Its firmware has no Secure Boot setting, so Secure Boot is not tested yet. See Secure Boot.
