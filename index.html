A Linux desktop for PCs, with a menu bar, a dock, and signed system updates.

Download

A menu bar, a dock, and search.

Menu bar

The focused application's menus, the clock, and the icons along the top.

Dock

The apps you keep, the ones that are open, and the Trash.

Search

Super + Space, for apps, arithmetic, and unit conversion.

Hold Alt and tap Tab to move between open applications. Files in the Desktop folder, and drives you plug in, sit on the wallpaper.

Settings for the desktop you see.

Wallpaper can be a dynamic picture, a landscape, or a picture of your own. The same window is where the dock, search, displays, and the account are set. A control center, opened from the icons at the right of the menu bar, comes later.

One folder for every application you add.

Applications is a single folder. Drop a Flatpak or an AppImage on it and Elavo adds it there, with the others. A Flatpak reference, a Flatpak bundle, and an AppImage are the same gesture.

Drag an entry to the dock to pin it, or onto the desktop to leave a shortcut. The application stays in the folder. Move the entry to the Trash and Elavo removes it. Applications that come with the system stay put.

Firefox is installed from Flathub the first time the PC is online, and that one can be removed. The folder itself is next. It is not in the image yet.

The system is one signed image.

You install Elavo from an ISO. An update replaces the whole system the next time you restart, and the previous build stays on the disk so you can fall back.

Intel and AMD graphics.

One installer for 64-bit desktops and laptops. NVIDIA comes later, in its own image. The first public ISO is not published yet.
