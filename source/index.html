Source

Elavo is built in the open, on GitHub.

  • elavo The system image: what is installed, how it is built, and the signing key.
  • elavo-folio The desktop shell: the menu bar, the dock, and search.
  • elavo-visuals The logo, boot animation, theme, and icons.
  • elavo.io This website.

Built on

  • Fedora, for the packages and the signed kernel
  • Universal Blue, for the base image and the build tooling
  • bootc, for image-based installs and updates
  • labwc, the Wayland compositor
  • Flathub, for applications
