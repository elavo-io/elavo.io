About

Elavo is a Linux desktop for PCs. You install it from an ISO, and it updates as one signed system image.

What is in it today

  • A menu bar across the top of the screen
  • A dock for the apps you keep, the ones that are open, and the Trash
  • Search, with Super + Space, for apps, arithmetic, and unit conversion
  • Alt + Tab to move between open applications
  • Files from the Desktop folder, and plugged-in drives, on the wallpaper
  • System Settings, including wallpaper, the dock, and search
  • Elavo's own boot animation and theme
  • Firefox from Flathub, installed the first time the PC is online

Applications

Adding software will happen in one folder, called Applications. You drop a Flatpak or an AppImage on it. A Flatpak reference, a Flatpak bundle, and an AppImage are the same gesture, and each one shows up in that folder.

Drag an entry to the dock to pin it, or onto the desktop to leave a shortcut. The application stays in the folder. Move the entry to the Trash and Elavo removes it. Applications that come with the system stay put. This folder is next. It is not in the image yet.

What comes next

  • The Applications folder, as above
  • A control center from the icons at the right of the menu bar
  • An image for PCs with NVIDIA graphics

How it is made

The system is built from Fedora through Universal Blue, as a container image. Each build is signed, and an installed PC moves to the next build in one step, keeping the previous one to fall back to. The desktop runs on the labwc Wayland compositor. The shell, artwork, and theme are Elavo's own. See Source.
